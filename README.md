# praw-moderation-bot

Minimal PRAW-based moderation tool for subreddit moderators.

## Purpose
This bot is designed to assist moderators by monitoring new submissions and comments and applying rule-based moderation logic.

## Functionality
- Reads new submissions from approved subreddits
- Designed for moderation and rule enforcement only
- No user interaction, messaging, voting, or content promotion

## Scope
- Operates only in subreddits where moderators explicitly approve its use
- Configuration is subreddit-specific and opt-in

## Technology
- Python
- PRAW (Python Reddit API Wrapper)

## Notes
This repository contains a public skeleton only.  
Production moderation logic and credentials are intentionally excluded for security reasons.
